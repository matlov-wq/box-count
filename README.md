# Box Verification Count

A scan-and-tally page for verifying box contents during inventory. Scan or type one SKU per entry; the page totals every SKU and exports a CSV or a copyable report.

- Works on any phone, tablet, or computer browser. No accounts.
- Counts save on the device, in that browser.
- Camera scanning (Code 128, Code 39, UPC/EAN, QR and more) needs the https link.

Hosted with GitHub Pages: upload these files to a repository, then Settings → Pages → Deploy from branch → `main` / root.

Barcode reading uses html5-qrcode (Apache 2.0, see `html5-qrcode-LICENSE.txt`).
